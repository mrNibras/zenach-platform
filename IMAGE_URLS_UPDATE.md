## 🎨 Image Specifications

All images use the following format for optimal performance:

```
https://images.unsplash.com/photo-{id}?w=600&h=400&fit=crop
```

**Parameters:**
- `w=600` - Width: 600px
- `h=400` - Height: 400px  
- `fit=crop` - Crop to fit dimensions

**For product cards (smaller):**
```
https://images.unsplash.com/photo-{id}?w=400&h=300&fit=crop
```

## 🔄 How to Add New Product Images

When adding a new product in admin:

1. **Click "Add Product"**
2. **Fill in product details**
3. **For Image URL**, use:
   ```
   https://images.unsplash.com/photo-XXX?w=600&h=400&fit=crop
   ```
4. **Replace XXX** with actual Unsplash photo ID

**Example:**
```
Name: Zenach Pro Runner
Price: 119.99
Image URL: https://images.unsplash.com/photo-1542291026-7eec264c27ff?w=600&h=400&fit=crop
```
